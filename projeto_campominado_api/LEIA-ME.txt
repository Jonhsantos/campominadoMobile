INSTALAÇÃO NO XAMPP
===================

1. Execute as queries do arquivo banco_dados.txt no Beekeeper.

2. Copie esta pasta inteira para o htdocs do XAMPP:

   De:  CampoMinado\projeto_campominado_api\
   Para: C:\xampp\htdocs\projeto_campominado_api\

3. Inicie Apache e MySQL no XAMPP.

4. Teste no navegador:
   http://localhost/projeto_campominado_api/listar.php

RETROFIT (Android)
==================

Emulador:  http://10.0.2.2/projeto_campominado_api/
Celular:   http://SEU_IP/projeto_campominado_api/  (ex: 192.168.15.100)
